I’m Orfeo, a software engineer with a soft spot for elegant systems, weird technical rabbit holes, and code that doesn’t
make future-me angry.

I take software engineering seriously: architecture, maintainability, performance, good abstractions, boring
reliability [...] the usual things nobody notices when they work.

I just don’t think we need to be serious about ourselves all the time.

This blog is where I write about software, technology, ideas I’m exploring, and the occasional nerdy detour that seemed
like a good use of an evening at the time.

Expect code, opinions, experiments, and very few inspirational quotes.
